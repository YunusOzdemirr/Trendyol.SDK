# Brand search

Status: **Experimental**

Trendyol.Sdk supports searching the Trendyol Türkiye product catalog for brands by name. The operation is based exclusively on the current official Product V2 documentation.

## API contract

| Item | Value |
|---|---|
| HTTP method | `GET` |
| Production route | `https://apigw.trendyol.com/integration/product/brands/by-name?name={brand-name}` |
| Stage route | `https://stageapigw.trendyol.com/integration/product/brands/by-name?name={brand-name}` |
| Authentication | HTTP Basic using the configured API key and API secret |
| Required User-Agent | Generated by the SDK from seller ID and integrator name |
| Name matching | Case-sensitive |
| Response | JSON array of brands |

Source: [official Trendyol brand documentation](https://developers.trendyol.com/docs/trendyol-marka-listesi-getbrands-1).

The SDK percent-encodes the query value but does not trim it, change its case, or otherwise normalize it. The official documentation does not define a length constraint or additional validation rule for this parameter.

## Usage

```csharp
using Trendyol.Sdk;
using Trendyol.Sdk.Configuration;

var options = new TrendyolOptions
{
    SellerId = 123456,
    ApiKey = "your-api-key",
    ApiSecret = "your-api-secret",
};

using var client = new TrendyolClient(options);

var brands = await client.Catalog.SearchBrandsByNameAsync(
    "TRENDYOLMİLLA",
    cancellationToken);
```

Dependency-injection consumers can inject the narrow feature interface:

```csharp
using Trendyol.Sdk.Catalog;

public sealed class ProductMapper(ICatalogClient catalog)
{
    public Task<IReadOnlyList<Brand>> FindBrandsAsync(
        string name,
        CancellationToken cancellationToken) =>
        catalog.SearchBrandsByNameAsync(name, cancellationToken);
}
```

## Response model

| Property | Type | Notes |
|---|---|---|
| `Id` | `long` | Trendyol brand identifier |
| `Name` | `string` | Brand name returned by Trendyol |
| `Luxe` | `bool?` | Optional because current official examples are inconsistent about the field's presence |

The current Turkish Product V2 example includes `luxe`, while official English examples omit it. The SDK preserves a supplied boolean value and returns `null` when the field is absent; it does not infer a value.

## Errors and cancellation

- HTTP 401 is mapped to `TrendyolAuthenticationException`.
- HTTP 429 is mapped to `TrendyolRateLimitException` and preserves a standard `Retry-After` value when supplied.
- Other non-success responses are mapped to `TrendyolApiException`.
- Invalid successful JSON responses surface as `JsonException`.
- Caller cancellation is preserved and no automatic retry is performed.

The paged `GET /integration/product/brands` operation is deliberately not implemented because the domestic documentation does not yet define an unambiguous page origin, defaults, and size rules.
